# Welcome Motor Video Assets

Place your homepage background video files in this folder.

Recommended video format:
- Format: MP4 (H.264 video codec + AAC audio) or WebM
- Resolution: 1920x1080 (Full HD) or 1280x720 (720p)
- Optimization: Compressed using Handbrake or online video compressor (recommended file size: under 15MB for fast loading)
- Filename: `hero-bg.mp4` or `showroom-tour.mp4`

Once placed here, you can set the video path in the **Admin Portal > Business Settings** to:
`assets/videos/hero-bg.mp4`
